# BetterShot onboarding media

## Style Prompt
Plain, calm examples of image annotation and video editing, using the bundled coastal practice photo. The app surrounds these illustrations with native system chrome. Keep a single scene and generous spacing; no pretend application chrome or promotional text.

## Colors
- Canvas: #EAE9E6, warm neutral
- Ink: #252629
- Annotation: #0865CE, blue
- Paper: #FFFFFF
- Border: #C6C7CA

## Typography
System sans serif (-apple-system, BlinkMacSystemFont, sans-serif). Large, readable labels only.

## Motion
Six seconds, silent, explicit play only, no loop. Brief opacity reveals for annotations; a deliberate zoom demonstrates video editing. Poster images convey the same idea without motion.

## What NOT to Do
No decorative gradients, animated chrome, ambient motion, generated logos, icon packs, or marketing slogans. Never present illustrative media as a recording of the app.
