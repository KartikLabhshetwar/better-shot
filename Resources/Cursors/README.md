# Classic macOS Poof cursor

`macOSPoof.png` is Apple's original transparent 72 × 90 pointer-guide artwork:
https://help.apple.com/assets/69DD569682238CF8EC0621E2/69DD569982238CF8EC0621E9/en_US/f8bf45001f73af236af8dee3a9860329.png

Source: https://support.apple.com/en-euro/guide/mac-help/mh35695/mac
Retrieved 2026-09-11. Artwork belongs to Apple.

The classic cloud matches the requested design; current `NSCursor.disappearingItem`
uses an X badge instead. Keep this source at its original resolution and alpha.
The arrow-tip hotspot is (17, 9) pixels; logical coordinates use half-size units.
This is recording artwork, not the application's interactive system cursor.
